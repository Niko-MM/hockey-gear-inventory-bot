# hockey-gear-inventory-bot

Telegram-бот для учёта товара и продаж в рознице хоккейной экипировки.

Стек: Python 3.13, [aiogram](https://docs.aiogram.dev/) 3.x, SQLAlchemy (async) + SQLite.

## Возможности (план MVP)

- Главное меню: продажа, поступление, остатки, сервис
- Номенклатура: модели, цвета, флекс, загиб, хват, продавцы; модель можно переименовать
- Финансы: остаток касс, зачисление опта, перевод, изъятие, подробный отчёт за период
- Поступление: город → конструктор или таблица Google → количество и закуп
- Продажа: город → модель/цвет → флекс → хват → загиб → партия → штуки → чек → касса
- Списание: Сервис → Списать, остаток без кассы, отмена в журнале
- В наличии: город → общее или хват → флекс (можно несколько) → загиб, список после каждого выбора
- Журнал: последние 20 операций или период, поступление из таблицы одной карточкой, отмена с откатом

## Локальный запуск

1. Создай виртуальное окружение и установи зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Скопируй `.env.example` в `.env` и заполни:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — твой Telegram user id (можно узнать у [@userinfobot](https://t.me/userinfobot))
- `DB_PATH` — путь к файлу SQLite (по умолчанию `data/bot.db`)
- `INCOME_SHEET_URL` — ссылка на лист Google Таблицы для пакетного поступления (доступ «все, у кого есть ссылка»). Без неё кнопки «Из таблицы» не будет.

Шапка листа: `фирма`, `модель`, `flex`, `загиб`, `хват`, `количество`, `цена закупа`, `цвет`. Город выбирается в боте. Цвет — как в справочнике (`белый`, `4 белый, 5 бордовый`). Пустая ячейка и остаток — стандарт.

Если файл `data/bot.db` уже создавался со старой схемой (с брендами) — удали его. Таблицы создадутся заново при следующем запуске.

3. Запусти бота:

```bash
python bot.py
```

Бот работает через long polling. Файл `.env` не коммитится.

## Docker

Локально или на сервере одинаково.

1. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`, `ADMIN_IDS` и при необходимости `INCOME_SHEET_URL`.
2. Запусти:

```bash
docker compose up -d --build
```

База создастся пустой в томе `bot-data`. Токен в образ не попадает.

Логи: `docker compose logs -f`  
Остановка: `docker compose down` (том с базой останется)

Обновление после `git pull`:

```bash
docker compose up -d --build
```

## Структура

- `bot.py` — точка входа
- `config.py` — настройки из окружения
- `db/` — модели, движок SQLite, сиды
- `handlers/` — сценарии Telegram
- `keyboards/` — клавиатуры
- `repositories/` — запросы к БД
- `Dockerfile`, `docker-compose.yml` — запуск в контейнере
- `requirements.txt` — зависимости
